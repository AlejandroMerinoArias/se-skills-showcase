# E-02 — Does the workspace build on Ubuntu 24.04 / Jazzy in WSL2, and does the simulator run with usable sensor rates?

## Question
Does the provided workspace build with colcon on Ubuntu 24.04 / ROS 2 Jazzy (WSL2), and does the
Unity binary run there with its sensor streams at a usable rate? Criteria: build = `colcon build`
exits 0 for all packages; rate = messages / wall-clock seconds over 30 s after the first depth image.

## Command
`wsl.exe bash tools/build_ws.sh` then, 3 times,
`wsl.exe bash tools/probes/sim_session.sh 200 <dir> -- python3 tools/probes/E-02_rates.py 30 <dir>/rates.json`

## Raw results
Build: `Summary: 4 packages finished [52.8s]` (simulation, controller_pkg, mav_msgs, mav_planning_msgs).
libsocket is fetched from GitHub at build time (network required).

| Run | Renderer | depth / semantic Hz | RGB-left Hz | state est. Hz | state max gap | RTF |
|---|---|---|---|---|---|---|
| llvmpipe (default) | CPU | 1.60 | 1.60 | 25.2 | 640 ms | 1.02 |
| 1 | D3D12 RTX 5060 Ti | 5.13 | 10.30 | 50.1 | 42 ms | 1.001 |
| 2 | D3D12 | 5.13 | 10.33 | 50.0 | 39 ms | 1.001 |
| 3 | D3D12 | 5.10 | 10.23 | 50.0 | 43 ms | 1.001 |

## Verdict
VERDICT: builds (4/4 packages); with `GALLIUM_DRIVER=d3d12` the simulator runs at depth 5.1 Hz,
RGB 10.3 Hz, state 50.0 Hz (mean of 3 runs, spread < 1 %). With the WSLg default (llvmpipe) all
cameras drop to 1.6 Hz, so GPU rendering is required on this host.

Other facts found on the way (used by the design):
- Provided `simulation.launch.py` has no GPU setting; Unity must be started with `GALLIUM_DRIVER=d3d12` on WSLg.
- Unity's `⟨redacted⟩` is not installed by CMake; it must be placed next to the `simulation` executables.
- Running `ros2 topic echo` concurrently with the launch start sent SIGINT to half the nodes
  (reproducible twice); readiness is now checked with an rclpy waiter (`tools/probes/wait_for_data.py`).
- The bridge declares a `UNITY_DETECTIONS` message type with no parser (null pointer if ever sent).

## Limits
Measured on the development host (RTX 5060 Ti, 16 cores). The customer's machine is native Ubuntu 24.04
(Q-03); its GPU and rates were not measured. Rates were measured with the UAV on the ground.
